
  # Luxury Travel Itinerary Design

  This is the codebase for Luxury Travel Itinerary Design.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.

  ## Deploying to Vercel

  This project is configured for static deployment on Vercel.

  1. Import the GitHub repository into Vercel.
  2. Keep the framework preset as `Vite`.
  3. Use `npm run build` as the build command.
  4. Use `dist` as the output directory.

  After deployment, Vercel will build and publish the site automatically on each push.
